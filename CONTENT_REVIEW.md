## Контроль изменений

Файл `content.js` формируется командой:

```powershell
npm run content:import
```

Импорт проверяет обязательные поля, уникальность ID и терминов, категории, уровень сложности, JSON-массив запрещённых слов и булево поле дополнительной проверки.

Любое изменение `cards.csv` изменяет SHA-256 и версию набора. После изменения необходимо:

1. повторно утвердить изменённый CSV;
2. обновить дату утверждения в `scripts/import-cards.mjs`;
3. выполнить `npm run content:import`;
4. выполнить `npm run lint`, `npm test` и `npm run build`;
5. зафиксировать новую версию в истории Git.
